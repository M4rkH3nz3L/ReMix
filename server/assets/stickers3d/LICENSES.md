# 3D sticker-modellek — licencek

Forrás: [Khronos glTF-Sample-Assets](https://github.com/KhronosGroup/glTF-Sample-Assets)
(a fájlok a `Models/<név>/glTF-Binary/<név>.glb` útvonalról származnak).

Minden alábbi modell **CC0 / public domain** (a Microsoft adományozta a Khronos
minta-gyűjteménybe), kereskedelmi felhasználásra is szabad, forrásmegjelölés
nem kötelező (de itt dokumentáljuk):

| Fájl | Modell | Licenc |
|---|---|---|
| Avocado.glb | Avocado | CC0 (Microsoft) |
| BoomBox.glb | BoomBox | CC0 (Microsoft) |
| Corset.glb | Corset | CC0 (Microsoft) |
| Lantern.glb | Lantern | CC0 (Microsoft) |
| WaterBottle.glb | WaterBottle | CC0 (Microsoft) |
| ToyCar.glb | ToyCar | CC0 (Microsoft) |

Új modell hozzáadásakor ide kerüljön a forrás + licenc sora. Csak CC0 vagy
kifejezetten engedélyezett licencű modell kerülhet a csomagba.
